# Security policy

## Supported versions

Only the latest version on the project’s default branch is currently supported.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues. If private vulnerability reporting is enabled for the repository, use GitHub’s **Report a vulnerability** flow. Otherwise, contact the maintainer through the private contact method on their GitHub profile and include reproduction steps and impact.

Please avoid including real API keys, personal information, or other users’ data in a report. The maintainer will acknowledge reports and coordinate a fix before public disclosure where practical.
