# ChromaWild

ChromaWild is a color walk and field journal for noticing color in everyday outdoor places. Explore parks, sidewalks, streets, transit stops, playgrounds, public art, water, the sky, plants, animals, and other things you come across outside.

Color quests are generated by a language model through Ollama. You can save observations and sketches in your browser, compare a photo with a quest color, and optionally listen to spoken prompts.

## Run locally

### Requirements

- Node.js 20.9 or newer and npm
- [Ollama](https://ollama.com/download) for AI-generated color quests

Install and start the model:

```bash
ollama pull gemma2:2b
ollama serve
```

In a second terminal, from the project directory:

```bash
npm ci
cp .env.example .env.local
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). If Ollama is already running, skip `ollama serve`. You can also configure the local Ollama address in the app’s Settings.

Without Ollama, the app still runs, but generating a new color quest needs a reachable Ollama instance and installed model. Spoken prompts use browser speech by default; ElevenLabs is optional.

## Configuration

Copy `.env.example` to `.env.local`. Keep `.env.local` and all real credentials private; they are ignored by Git.

| Variable | Purpose | Default |
| --- | --- | --- |
| `OLLAMA_BASE_URL` | Ollama address used by the server | `http://localhost:11434` |
| `OLLAMA_MODEL` | Ollama model used to generate color quests | `gemma2:2b` |
| `GROQ_API_KEY` | Optional server-side key for AI-assisted field-note evaluation | unset |
| `ELEVENLABS_API_KEY` | Optional server-side key for generated speech | unset |

The Settings screen also accepts an Ollama URL and an optional ElevenLabs key in this browser. These values are stored in `localStorage`. A browser-provided ElevenLabs key is sent to this app’s `/api/tts` route when requesting speech. Use a private, trusted deployment if you enter a personal key. Without a key, the browser speech engine is used.

Ollama requests run from the Next.js server. On a hosted deployment, `localhost` refers to the server, not a visitor’s computer; the server needs access to the configured Ollama instance. The API routes currently have no authentication or rate limiting, so do not expose a deployment that uses your private Ollama service or provider credentials to the public internet without adding those protections.

## Data and privacy

- Field entries, progress, audio preferences, and Settings are stored in the current browser’s `localStorage`; they are not synced between browsers.
- Color matching runs in the browser. Photos and sketches are stored in that browser. The app sends color values, palette details, and optional notes to `/api/gemma` for field-note generation; it does not upload the photo for that request.
- If you configure Groq or ElevenLabs, the corresponding server route sends the relevant prompt or text to that provider. Review their policies before using those services.
